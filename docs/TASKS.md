## Задача 1 — «Метод»: сетка плиток → органическая спираль/кольцо

**Файл:** `app/page.tsx`, секция `Метод` (сейчас строки ~54–77): заголовок +
сетка `grid-cols-2 sm:grid-cols-3 lg:grid-cols-6` из 6 карточек-шагов
(`Человек`, `Отношения`, `Команда`, `Руководитель`, `Организация`, `Среда`).

**Что сделать:** заменить прямоугольную сетку на SVG-визуализацию в виде
спирали или замкнутого кольца — это сквозной мотив сайта («спирали и
закольцовывания»), сейчас реализован только текстово. 6 шагов должны быть
узлами вдоль кривой, а не карточками в сетке.

**Техника-референс** (только техника, НЕ цвета — в EvenEsh своя палитра):
`F:\EvenEsh\app\globals.css` — `@keyframes spiral-draw / spiral-return /
spiral-node / spiral-halo / sign-core`. Подход: SVG `<path>` с
`pathLength="1"`, анимация через `stroke-dasharray`/`stroke-dashoffset` как
безразмерные величины (0→1), узлы — `opacity`+`transform: scale()` вместо
анимации радиуса (не даёт лишний reflow).

**Приёмка:**
- `npm run build` проходит без ошибок;
- визуально не прямоугольная сетка — узлы на кривой;
- корректно на мобильных (без горизонтального скролла);
- **проверить**, есть ли в `F:\Semerdjidi\app\globals.css` блок
  `@media (prefers-reduced-motion: reduce)` — если нет, добавить (в EvenEsh
  он уже есть и гасит все анимации/transition до 0.01ms).
